# Explorador de Séries

Aplicação frontend para buscar séries na API pública TVMaze, visualizar informações como poster, ano, nota, gêneros e resumo, e salvar séries em um banco PostgreSQL com Supabase.

Comando para executar localmente com Docker:

```bash
docker run -d -p 8080:80 davileitem/explorador-series:latest
```

Repositório do projeto: https://github.com/davileitee/ExploradorDeSeries

GitHub Pages: https://davileitee.github.io/ExploradorDeSeries/
